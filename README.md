# Coffee Match — iPad-ассистент для фестиваля

Квиз на 6 вопросов (EN): по ответам подбирает один товар из зерна, капсул, дрипов и банок Nitro Cold Brew.
Старт — тёмный экран с живой сферой; по тапу она взрывается в оранжевый градиент, поверх которого наплывает панель с вопросами.
Перед результатом — экран загрузки с галочками, на результате — QR на страницу товара в e-shop и отправка картинки результата по AirDrop.
Сделан как PWA: обычный сайт, который ставится на iPad как приложение и работает без интернета.

## Как поставить на iPad

1. Сейчас приложение опубликовано на GitHub Pages: https://pavelmenshchikov-crypto.github.io/coffee-match/
   (репозиторий https://github.com/pavelmenshchikov-crypto/coffee-match — эта папка `Export`).
2. На iPad открыть ссылку в **Safari** → «Поделиться» → **«На экран Домой»**.
3. Запустить с иконки. Приложение откроется во весь экран, без адресной строки, и сохранит всё нужное для работы офлайн.
4. Заблокировать iPad на приложении: Настройки → Универсальный доступ → **Гид-доступ** → включить, затем в приложении трижды нажать боковую кнопку.
5. Настройки → Экран и яркость → Автоблокировка → **Никогда**.

## На стенде

- Если на вопросе ~40 секунд никто ничего не нажимает (на результате ~75 секунд), появляется «Still there?», а ещё через 10 секунд квиз возвращается на старт.
- **Админка: 5 быстрых тапов по стрелке-логотипу** в правом верхнем углу стартового экрана.
  По умолчанию на баре фестивальный набор (`onBar: true` в `data.js`): Kello Siko #3, Kenya Gititu, Guava Banana — коробки 250 г; дрипы Rocket Flower и Dreyde Perez Geisha.
  Варианты ответа и вопросы, для которых на баре ничего нет, прячутся сами: без капсул нет «Nespresso», без банок — «cold one», без декафа — вопроса про кофеин.
  Кнопка «Festival set» возвращает набор по умолчанию.
- **Share to your device** открывает системное меню iOS с картинкой результата — можно отправить её по AirDrop на телефон гостя.
  У гостя AirDrop должен принимать от «Все на 10 минут». Если не выходит — QR в таблице результата ведёт на страницу товара. Там отключаются товары, которых сегодня нет на баре — они перестанут рекомендоваться. Настройка хранится на этом iPad.

## Как править

| Что | Где |
|---|---|
| Товары, шкалы вкуса, фото пачек | `data.js` → `TM_PRODUCTS` |
| Заголовок и таблица на экране результата | `data.js` → `TM_DETAILS` |
| Вопросы, подсказки, варианты, раскладка | `data.js` → `TM_QUESTIONS` |
| Строки экрана загрузки | `data.js` → `TM_LOADING` |
| Сфера, взрыв, живой фон (WebGL) | `fx.js` — цвета, блюр и сила «пламени» в начале шейдера |
| Фон после взрыва | `assets/bg/gradient.png` (картинка из Photoshop) |
| Тайминги анимаций | `app.js`, константы вверху |
| Логика подбора и веса | `match.js` |
| Внешний вид | `styles.css` |

У 7 товаров на сайте нет шкал кислотности/горечи/сладости (капсулы Brazil и Rocket Flower, все дрипы, обе банки).
Значения прикинуты по описанию и помечены `tasteEstimated: true` — их лучше сверить с обжарщиком.

**После любой правки** увеличьте номер `VERSION` в `sw.js`, закоммитьте и сделайте `git push`. GitHub Pages обновится за 2–5 минут.
Пока есть интернет, приложение всегда берёт свежие файлы с сервера. Кеш используется, только когда сети нет или она не ответила за 3 секунды.
`VERSION` нужен, чтобы офлайн-кеш пересобрался целиком.
